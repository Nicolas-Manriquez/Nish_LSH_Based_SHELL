# Nish_LSH_Based_SHELL

Este proyecto está basado en el tutorial **[Tutorial - Write a Shell in C](https://brennan.io/2015/01/16/write-a-shell-in-c/)**
de **Stephen Brennan**, y en su implementación original
[lsh](https://github.com/brenns10/lsh).

El código lo escribí yo como ejercicio de aprendizaje siguiendo su
explicación, con modificaciones y agregados propios. Todo el mérito del diseño original y
de la explicación del funcionamiento de una shell (ciclo de lectura,
parseo, `fork`/`exec`/`wait` y comandos internos) le pertenece a él.
